# Olanozun Maria Raiwe - Product Leader Website

A professional website for Olanozun Maria Raiwe, showcasing expertise in product management, platform scaling, and technology leadership.

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Testing**: Jest & React Testing Library
- **Deployment**: Vercel (recommended)

## Project Structure
olanozun/
├── src/
│ ├── app/ # Next.js App Router pages
│ │ ├── about/ # About page with bio and timeline
│ │ ├── blog/ # Blog listing and individual posts
│ │ ├── portfolio/ # Portfolio and case studies
│ │ ├── contact/ # Contact form with engagement types
│ │ └── layout.tsx # Root layout with metadata

│ │ ├── layout/ # Header, Footer, Navigation

│ ├── content/ # Static content and data
│ └── lib/ # Utilities and constants
├── public/ # Static assets
│ └── images/ # Profile and project images
└── tests/ # Test files
